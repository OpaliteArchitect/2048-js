# 2048

A completely free client-side 2048 game.

[Click here to play.](https://opalitearchitect.github.io/2048-js)

![2048](./assets/2048-js.png)

**Features:**

- Infinite replayability
- High score persistence
- Dynamic tile colors!
- Available in any platform
- Keyboard-accessible
